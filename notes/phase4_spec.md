# Phase 4 spec: ablations of the locked strictly unpaired model (agreed)

One page. Phase 4 explains the locked M1; it selects no new model and changes nothing that goes to test. Output: a table of what each component does, and design implications for Phase 5.

## Reference and protocol
- **Full model:** the locked M1 setting (λ_cyc = 20, identity loss on, discriminator learning rate 2 × 10⁻⁴, baseline starts, learnable per-gene scale, residual branch), halving 0, 20,000 steps.
- **Fresh seeds.** The full model and every ablation run on **seeds 3–5**. Seeds 0–2 won M1's selection on these validation pairs; comparing new runs against them would bias every difference toward "the component helps". Seeds 0–2 are used only for the equivalence check.
- **One change per ablation**; data, steps, evaluation every 500 steps and the Phase 3 checkpoint rule unchanged.
- **Readouts, per direction, on the 135 validation pairs (14 donors):**
  - *Primary (no selection):* the mean over the last quarter of training of margin, centered R², realism, marker-probe composition R²; and the move from the generator start (Δ centered R², Δ realism), since the margin is about 0 for anything that stays near a baseline.
  - *Secondary:* the same at the selected checkpoint, the chosen step, and the last checkpoint; within-donor top-1, diversity ratio, granulocyte gap.
  - Each as the difference from the full model on seeds 3–5, with the seed SD and a donor-bootstrap 95% CI (1,000 resamples, seeds averaged inside each resample). The CI covers donor sampling only, not training noise, and uses the same 14 donors that chose M1, so it is optimistic. Differences in the selected margin below about 0.06 are within checkpoint-to-checkpoint noise; the last-quarter readouts get their own seed SD.
- **Phase 3 grid slices** (cycle weight 5/10/20, identity on/off, discriminator learning rate; for M2, task weight 0.1/1/10), reported without new runs and labeled "from the selection grid, biased toward the locked values".

## Analyses of existing runs (no training)
- **P0. Signal or spread?** For each chosen M1 checkpoint (Phase 3, seeds 0–2), split the move from the start, δ = G(x) − start(x), against the needed correction r = y − start(x): the part along r versus the rest; and plot accuracy, realism and ‖G(x) − start(x)‖ over training from the logs. Tells whether M1's move is signal or added spread, and whether realism plateaus while accuracy keeps falling. Two references make the share interpretable, since r is mostly noise even for the best paired methods: the same decomposition for ridge + spread's move from the same start (an informed correction), and a null with y replaced by another donor's target (a move with no signal). Seeds 0–2's chosen checkpoints are selection-biased, so P0 is repeated on the seeds 3–5 full-model runs (last-quarter checkpoints, no extra training). P0 is also applied to M2: composition against ‖G(x) − start(x)‖ for M1 and M2 checkpoints at the same distance from the start. If M2's composition gain is mostly that it drifts less, an unpaired drift penalty could recover much of it (Phase 5); if M2 is better at the same distance, the task loss adds information that anchoring cannot replace.

- **P1. Is "on the frontier" specific to the realism metric?** Realism is a logistic-regression classifier two-sample test on the top 10 target PCs and their squares, which mostly checks the mean and spread along those PCs, while the GAN trains against an MLP discriminator on all 5,000 genes. Rescore, with no training, the Phase 3 chosen checkpoints of M1 and M2, the seeds 3–5 full-model runs and every frontier blend point under two alternative realism measures: (a) the same classifier on the top 50 PCs; (b) a small nonlinear classifier (gradient-boosted trees or a one-hidden-layer MLP, fixed settings, same cross-validation) on the top 50 PCs. Report each alternative's frontier and M1's margin, and also MMD (already computed) against its own frontier. Each alternative is calibrated before any margin is read: its classifier settings are fixed before scoring any model, with donor-grouped cross-validation, and two nulls are reported (real training vs. real validation targets, and the paired-swap null), with each metric's null spread (`c2st_null`). Circularity: M1 was trained against an MLP discriminator and may score well against an MLP-like classifier partly for that reason; stated with the result. A metric whose real-vs-real null is not near AUROC 0.5 is reported as unusable (a quadratic C2ST on 50 PCs fit on training targets scored 0.96 in Phase 1, which is why the H1 metric uses 10). MMD's frontier uses its lower-is-better convention. The seeds 0–2 checkpoints were selected under the original metric; the seeds 3–5 runs give the unselected comparison. Descriptive: the H1 metric stays as fixed in Phase 3.

## Ablations (seeds 3–5, halving 0)
| # | Change | Question | Informs Phase 5 |
|---|---|---|---|
| A1 | **Adversarial loss off** (weight 0 by exact multiplication; discriminators still trained, all random draws unchanged) | Do the cycle and identity losses alone move M1 off its start? | If it drifts: the cost comes from the regularizers → a start-anchored identity loss / drift penalty. If it stays: the adversarial term causes the loss of accuracy and composition, and anchoring only trades along the frontier |
| A2 | **Affine-only generator** (residual branch removed; per-gene a, b learned adversarially), as a 2 × 2 with the identity loss: residual on/off × identity on/off | Does M1 use any cross-gene capacity on real data? The identity loss pulls an affine model's bias back toward 0 (it cannot make its shift input-dependent), so without the identity-off pair a worse affine model could reflect the identity loss rather than missing capacity; the pair also gives a fresh-seed identity-loss ablation | If it matches M1: the GAN is effectively choosing per-gene scales, the frontier is close to an information limit, and Phase 5 should add information (M2-style) rather than generator tricks. If M1 is clearly better: keep the residual and constrain it |
| A3 | **Cycle weight beyond the grid:** λ_cyc = 0 (identity loss kept) and λ_cyc = 40 | What keeps M1 near the data, and is the locked value (at the grid's edge) on a plateau? | Whether the content-preserving lever is the cycle loss or the identity loss |
| A4 | **Donors vs. draws:** ½ of the donors per half (all their draws) vs. all donors with ~½ of their draws, sample counts matched within ±5%, age-stratified; a different subset for each seed (donor and draw lists saved); the baselines and the frontier refit on each reduced set, with the margin also reported against the full-halves frontier, and raw accuracy and realism | Does the GAN's position depend on the number of donors or of samples? | Whether more (or augmented) data is worth pursuing |

## Weakly paired model (M2; seeds 3–5, halving 0)
H2 shows that M2's task loss improves composition over M1 (+0.189 and +0.273 under the marker probe on validation), but not beyond ComBat. These ablations ask where that help comes from and how much pair information it needs.

| # | Change | Question |
|---|---|---|
| B0 | **M2 reference** on seeds 3–5 (the locked M2 setting) | the comparison point for B1–B3, free of selection bias |
| B1* | **Single-cell → bulk task term only** (target: the measured composition of the single-cell sample, read through $C_B$) | Does the help come from supervising the translated bulk profiles? |
| B2* | **Bulk → single-cell task term only** (target: $C_B$'s reading of the bulk input) | Does it come from the pseudo-labels on the bulk side? |
| B3 | **Out-of-sample $C_B$:** the same architecture and epochs, retrained on half A's bulk pairs only, so that its readings of half B's bulk profiles are as noisy as on new donors (composition R² ≈ 0.47 rather than 0.98 on its own training rows); used in both task terms | How good must the weak labels be: does the gain survive realistic, out-of-sample pseudo-labels? |

B3's networks are trained with the Phase 2 code (`freeze_nets`, the frozen configurations) on half A's training rows only: $C_B$ on half A's bulk pairs, and $C_S$ on half A's single-cell profiles (no pairs needed; the locked $C_S$ also saw half B's single-cell profiles, which the halves design treats as unused). *B1 and B2 run only if B3's marker-probe composition gain over M1 (seeds 3–5) is below half of B0's gain in either direction, to find which term carried it; if the gain survives B3, splitting it between the terms changes no Phase 5 decision. The half-A networks' validation composition R² is reported next to the locked networks' (a weaker readout network would otherwise be confused with weaker labels). B3 changes two things at once, label quality and training size (about 288 pairs instead of 582); stated as a confound. Optional if the budget allows: a cross-fitted $C_B$ (each half-B label predicted by a network not trained on that donor) separates the two at almost the full training size. B1 and B2 report marker-probe composition R² in both directions, since a single task term may help its own direction and cost the other.

Fewer epochs per sample matter at reduced size (same 20,000 steps); stated as a caveat, not corrected.

## Instrumentation of the full-model runs
An exponential moving average of the generator weights (decay 0.999) is kept and scored at every evaluation alongside the raw weights, without affecting training, on the seeds 3–5 full-model runs only (off for the equivalence runs). Tests weight averaging, a Phase 5 candidate, at no extra training.

## Runs and code
- Runs: equivalence 3 + full model 3 + A1 3 + A2 9 (affine-only with identity on, full model and affine-only with identity off) + A3 6 + A4 6 + B0 and B3 6 = 36 (about 8.5 hours at 6 workers, one night); + B1, B2 6 if triggered. P1 is rescoring only (about an hour).
- `dgm/translation.py`: config keys `lambda_adv` (default 1, exact multiply), `affine_only` (default False), EMA scoring (default off); `SoundLife(halving, subset=...)` with the frontier refit on a subset. **Equivalence check:** the full model on seeds 0–2 under the new code must reproduce Phase 3's canonical state hashes (`models.json`) and per-evaluation margins; the default subset must reproduce `frontier_val_halves.csv`.
- Tests: B1/B2 zero exactly one task term; B3's networks never see a half-B row; A1 changes no random draw (identical batches); A2 has no residual parameters; subsets are donor-disjoint subsets of the halves with matched counts; a run with EMA scoring on and one with it off give identical canonical state hashes and per-evaluation margins (no random draw or evaluation order changes).
- Notebook `phase4_ablations.ipynb`: P0; P1 (frontiers under the alternative realism measures); the ablation table; A1 and A3 (λ_cyc = 0) as trajectories over checkpoints on the accuracy–realism plane with the frontier; A4 table; the M2 table (B0–B3, marker-probe composition primary); EMA vs. raw weights; Implications for Phase 5.

## Scope and link to test
If the budget allows after the main runs, A1 and A2 on halving 1 are the first addition (M1's bulk → single-cell margin is −0.332 there); optional. Not in Phase 4: M2 task-weight sweeps beyond the Phase 3 grid, the no-baseline-start ablation (the pilot showed the start matters), discriminator variants, halving 1, bagging, anything on test. The proposal's "residual vs. plain generator" ablation is replaced by A2 (deviation log). The Phase 3 hypotheses on test apply only to the locked M1 and M2; any Phase 5 model sent to test is exploratory, reported with the total number of configurations compared on validation and the statement that its design used Phases 3–4 validation results.

## Amendment (2026-10-12, after the pre-run code audit; before any Phase 4 result was read)
- **Bootstrap CIs** only for centered R² and marker-probe composition R², at the kept checkpoints (steps 15,000, 17,500, 20,000); realism and margin (including the primary last-quarter margin) get seed SDs only, since a C2ST per resample costs about 5 hours per comparison. Table captions say so.
- **P1 calibration:** real training targets against real validation targets (disjoint donors), in an unpaired C2ST with donor-grouped folds, for each measure including the H1 measure as a reference; plus the paired swap null around M1. The "other draw of the same donor" construction was dropped (with a fixed choice of draw it measured a collapsed set, not realism).
- **Usability rule** for an alternative measure: |AUROC − 0.5| < 2 × swap-null SD + 0.05 on real training vs real validation targets.
- **A3** holds the identity-loss weight at the locked 10 for both λ_cyc = 0 and 40 (in the Phase 3 grid it was tied to 0.5 λ_cyc), so each is a single change.
- **B1/B2 trigger** counts a direction only where M2's own marker-probe gain over M1 is positive.
- Also: a CI row for M2 against M1 on the fresh seeds; P1 scores all kept checkpoints of seeds 3–5; a figure of the distance from the start over training; an assert that the H1-measure frontier recomputed in P1 matches Phase 1's.
